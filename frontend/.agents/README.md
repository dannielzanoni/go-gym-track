# Agentes do GymTrack

Esta pasta descreve responsabilidades sugeridas para evolução do produto. Cada agente deve preservar a separação entre interface, regras de negócio e persistência.

- `frontend-agent.md`: arquitetura React, rotas e componentes.
- `ui-agent.md`: design system, acessibilidade e responsividade.
- `data-agent.md`: modelos, armazenamento local e futura integração com API.
- `qa-agent.md`: critérios de aceite, testes e regressões.
