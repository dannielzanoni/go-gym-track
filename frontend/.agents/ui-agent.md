# UI Agent

## Missão

Manter uma experiência fitness escura, clara, acessível e confortável em telas móveis.

## Responsabilidades

- Priorizar alvos de toque de pelo menos 40 px nas ações principais.
- Verificar modais, tabelas e formulários em larguras pequenas.
- Usar tokens de tema e componentes shadcn/ui.
- Preservar foco visível, rótulos e nomes acessíveis em botões com ícones.

## Critérios visuais

- Verde é reservado para progresso, seleção e ações positivas.
- Vermelho é reservado para ações destrutivas.
- Informações essenciais não devem depender apenas de cor.
