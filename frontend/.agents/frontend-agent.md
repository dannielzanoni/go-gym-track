# Frontend Agent

## Missão

Evoluir a aplicação React mantendo componentes pequenos, tipados e organizados por domínio.

## Responsabilidades

- Preservar as rotas `/` e `/muscles`.
- Manter regras de treino fora dos componentes puramente visuais.
- Reutilizar componentes em `src/components/ui` antes de criar novos elementos básicos.
- Validar o projeto com `npm run build` após alterações relevantes.

## Limites

- Não acessar `localStorage` diretamente em páginas ou componentes.
- Não acoplar a interface a um formato específico da futura API.
